Student Registration

Saturday-school enrolment and payments for the Dhamma & Sinhala School of Canberra. Parents register children and pay by Stripe; staff manage the roster, medical notes and class placement. It is the source of truth the sibling attendance and tea-roster apps sync from.

Key features

👨‍👩‍👧

Family registration

Parents enter their details and every child; an update link lets them edit the registration later.

💳

Stripe payments

Annual fees by Stripe Checkout; admin payment override marks paid or reverts with a reason.

🏫

Auto class allocation

On payment, ClassAllocator maps day-school year → class using config/integration.php.

🔀

Class relocation

Search any student and move class; parents are emailed when the class actually changes.

🩺

Allergies & medical

One page listing every student with a real allergy or special need, with class and contacts.

🔗

Integration API

Token-gated /api/integration/changes?since= deltas for attendance and tea-roster; no contact/DOB data in the attendance feed.

📥

CSV import / export

Bulk parent/child data, export includes payment status and student ID (RFC 4180).

🔄

Annual reset

Each year families flip back to pending while payment history is kept.

🔑

Roles & audit

Staff roles with permission atoms and an append-only activity log.

❓

In-app help

Screenshot-led parent guide at /help and staff guide at /admin/help.

⚙️

School-configurable

Name, pricing, minimum age, WhatsApp link and Stripe key all come from .env / config/custom.php.

🛡️

Test-DB guard

phpunit.xml forces the test DB and TestCase re-asserts it, so tests can't wipe real data.

Data handling — children's records

✅ Rules

  • Only paid students and class codes go to the attendance feed
  • Each consuming app gets its own revocable API token
  • Tests only ever touch student_reg_test / student_reg_dusk
  • Medical page is behind staff login and permission atoms

⛔ Never

  • Expose parent contacts or DOB through the attendance API
  • Run migrations or seeders against production from a dev box
  • Commit Stripe keys or .env
